버스편전국 고속·시외버스 시간표

버스편 소개

버스편은 전국 고속버스·시외버스의 출발 시각, 도착 시각, 요금, 소요 시간을 터미널별·구간별·도시별로 보여 주는 사이트입니다. 검색에서 바로 답을 찾을 수 있도록 모든 구간을 각각의 페이지로 만들었습니다.

데이터

시간표는 국토교통부 국가대중교통정보센터(TAGO)가 공공데이터포털(data.go.kr)에 공개한 고속버스정보·시외버스정보 API에서 매일 새벽 받아 옵니다. API가 당일 배차만 주기 때문에 페이지마다 기준 날짜를 적어 두었습니다. 요일이나 명절에 따라 실제 운행이 다를 수 있으니 출발 전 예매 사이트나 터미널에 확인하세요.

시외버스는 TAGO API가 제공하는 터미널만 다룹니다. 모든 시외버스 정류소가 들어 있지는 않습니다.

예매

이 사이트는 예매 기능이 없습니다. 고속버스는 KOBUS, 시외버스는 티머니 시외버스·버스타고에서 예매할 수 있으며 각 페이지에 링크를 두었습니다.

운영

버스편은 flowtrace가 운영하는 개인 프로젝트이며 광고 수익으로 유지됩니다. 잘못된 정보나 제안은 GitHub 저장소 이슈로 알려 주세요.

시간표와 요금은 국토교통부 TAGO 공공데이터에서 매일 받아 옵니다. 요금은 어른 편도 기준이며 터미널 사정으로 실제와 다를 수 있습니다.
